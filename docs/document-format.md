# The document format (PhotoDoc)

A picture is `photo.json`, a **PhotoDoc**: a canvas and a non-destructive stack of layers. Source files (photos, AI masks, painted edits) live in the project's `assets/`; everything else — placement, opacity, blend modes, masks, filters, looks, layer effects, text, shapes — is data the engine composites deterministically. The render is a pure function of (document, files, fonts).

The TypeScript definition is [`src/core/types.ts`](../src/core/types.ts); validation is [`src/core/validate.ts`](../src/core/validate.ts); every filter, look, effect, font and size preset with its parameters is in the [catalog](catalog.md) (`agentphoto catalog`).

Conventions: coordinates are canvas pixels, origin top-left, y down. Angles are degrees, clockwise. Colours are CSS strings (`"#ff3366"`, `"rgb(255 51 102)"`, `"rgba(0,0,0,0.5)"`, `"hsl(340 100% 60%)"`, named colours). **Layers are listed bottom → top** (the last one is drawn on top); `doc summary` and `layer list` print them top → bottom.

## A complete example

```json
{
  "version": 1,
  "id": "lake-post",
  "title": "Square post with a caption",
  "description": "A mountain lake at golden hour with the caption Slow mornings at the lake",
  "canvas": { "width": 1080, "height": 1080, "background": "#0b1320" },
  "layers": [
    { "id": "photo", "type": "image", "src": "library:landscape", "x": 0, "y": 0, "width": 1080, "height": 1080, "fit": "cover", "focus": [0.55, 0.5],
      "filters": [{ "type": "look", "look": "golden-hour", "amount": 0.6 }] },
    { "id": "shade", "type": "fill", "fill": { "type": "linear", "angle": 90, "stops": [[0, "rgba(11,19,32,0)"], [0.55, "rgba(11,19,32,0)"], [1, "rgba(11,19,32,0.85)"]] } },
    { "id": "title", "type": "text", "text": "Slow mornings\nat the lake", "x": 72, "y": 800, "width": 936, "font": "playfair", "size": 84, "weight": 700, "lineHeight": 1.05, "color": "#ffffff",
      "effects": { "dropShadow": { "opacity": 0.4, "blur": 18, "distance": 4 } } }
  ],
  "export": { "format": "jpeg", "quality": 88 }
}
```

## Root

| Field | Type | |
|---|---|---|
| `version` | `1` | Format version (`DOC_VERSION`). Required in practice; a missing one is assumed with a warning. |
| `id` | string | A slug (`[a-zA-Z][a-zA-Z0-9_-]*`); default export file name. |
| `title`, `description` | string | `description` is the alt text of the picture. |
| `canvas` | object | `width`, `height` (integers, 1..16384) and `background` (a paint; omitted or `null` = transparent). Above 40 megapixels validation warns. |
| `layers` | Layer[] | Bottom → top. |
| `export` | object | Default export settings: `format` (`png` / `jpeg` / `webp` / `avif`), `quality` (1..100), `scale`, `width`, `height`, `background`, `name`. CLI options override them. |

## Paints and gradients

A paint is a CSS colour or a gradient. Gradient `stops` are colours spread evenly or `[offset 0..1, colour]` pairs.

```json
{ "type": "linear", "angle": 90, "stops": ["#1b1340", "#ff7a59"] }
```

`angle`: 0 = left → right, 90 = top → bottom. Radial: `{ "type": "radial", "stops": [[0, "#ffd166"], [1, "rgba(255,209,102,0)"]], "cx": 0.5, "cy": 0.5, "radius": 1 }` (centre and radius are fractions of the painted box). A radial gradient follows the box's proportions: a circle on a square box, an ellipse on a wide or tall one (half-axes = width / √2 and height / √2 × `radius`, so `radius: 1` reaches the corners) — a radial fill on a flat ellipse fades towards its top and bottom edges as well as its ends.

## Common layer fields

| Field | |
|---|---|
| `id` | Unique across the document, groups included. Patches, masks generated by the AI and the Studio refer to it. |
| `type` | `image`, `text`, `shape`, `fill`, `adjustment`, `group`. |
| `name` | Display name (Studio). |
| `visible` | `false` = not rendered, not exported. |
| `locked` | Studio only: not selectable by hand. |
| `opacity` | 0..1 (not percent). |
| `blend` | `normal`, `multiply`, `screen`, `overlay`, `darken`, `lighten`, `color-dodge`, `color-burn`, `hard-light`, `soft-light`, `difference`, `exclusion`, `hue`, `saturation`, `color`, `luminosity`. |
| `mask` | See [Masks](#masks); `null` removes it. |
| `clip` | Clipping mask: draw only where the layer directly below is opaque. |
| `filters` | `[{ "type": …, …params }]`, applied in order to this layer's pixels. |
| `effects` | Layer styles: `dropShadow`, `outerGlow`, `innerShadow`, `stroke`, `colorOverlay` (each an object of parameters, `null` removes it). |

Image, text and shape layers also have a **box**: `x`, `y` (top-left), `width`, `height`, `rotation` (around the box centre), `flipX`, `flipY`.

## Layer types

**image** — a photo from the project (`"src": "assets/images/photo.jpg"`) or the built-in library (`"src": "library:portrait"`). Without `width` / `height` it takes the source's natural size. `crop` `{ x, y, width, height }` (source pixels) crops before placing; `fit` decides how the (cropped) image fills its box: `fill` (stretch, default), `cover` (fill and crop the overflow), `contain` (fit inside); `focus` `[x, y]` (0..1) aligns cover / contain.

**text** — `text` (`\n` for line breaks), `font` (a bundled font id such as `inter`, `playfair`, `bebas-neue`; another family renders with what the computer has, with an info issue), `size` (px, default 64), `weight` (100..900), `italic`, `color` (paint, default white), `align` (`left` / `center` / `right`), `valign` (`top` / `middle` / `bottom` inside an explicit `height`), `lineHeight` (default 1.2), `letterSpacing` (px), `transform` (`uppercase` / `lowercase`), `width` (wraps the text), `background` `{ "color", "padding": 12 | [h, v], "radius" }` (a label or pill behind the text).

**shape** — `shape`: `rect`, `ellipse`, `line`, `polygon`, `star`; `width` and `height` are required; `fill` (paint, `null` = none), `stroke` `{ "color", "width", "dash": [12, 6] }`, `radius` (rect corners), `sides` (polygon / star points), `innerRadius` (star, 0..1).

**fill** — `fill` (paint) covering the whole canvas: backgrounds, colour washes, gradient shades for text contrast. Shape it with a mask.

**adjustment** — `filters` applied to **everything below it** (inside its group): global corrections that stay editable. A `look` filter here grades the whole picture.

**group** — `children` (bottom → top). Opacity, blend, mask and filters apply to the group as a whole.

```json
{
  "version": 1,
  "id": "types-demo",
  "canvas": { "width": 1200, "height": 630, "background": { "type": "linear", "angle": 20, "stops": ["#12082e", "#5b2bd6", "#ff4f81"] } },
  "layers": [
    { "id": "glow", "type": "shape", "shape": "ellipse", "x": 640, "y": 40, "width": 560, "height": 560, "fill": { "type": "radial", "stops": [[0, "rgba(255,214,102,0.55)"], [1, "rgba(255,214,102,0)"]] } },
    { "id": "photo", "type": "image", "src": "library:product", "x": 660, "y": 80, "width": 480, "height": 480, "fit": "cover", "focus": [0.7, 0.5],
      "mask": { "shape": "ellipse", "x": 0, "y": 0, "width": 480, "height": 480, "feather": 4 },
      "effects": { "stroke": { "color": "#ffffff", "width": 10 } } },
    { "id": "heading", "type": "group", "children": [
      { "id": "title", "type": "text", "text": "Morning brew", "x": 64, "y": 200, "width": 560, "font": "anton", "size": 110, "color": "#ffffff", "transform": "uppercase",
        "effects": { "dropShadow": { "opacity": 0.5, "blur": 0, "distance": 8 } } },
      { "id": "tag", "type": "text", "text": "NEW", "x": 64, "y": 130, "font": "montserrat", "weight": 800, "size": 32, "color": "#12082e", "background": { "color": "#ffd166", "padding": [16, 8], "radius": 6 } }
    ] },
    { "id": "grade", "type": "adjustment", "filters": [{ "type": "vibrance", "vibrance": 15 }, { "type": "vignette", "amount": 20 }] }
  ]
}
```

## Filters

A filter is `{ "type": "<catalog id>", ...params }` with two common parameters: `amount` (0..1, blend with the unfiltered pixels, default 1) and `enabled` (`false` keeps it but skips it). Groups: light (`brightnessContrast`, `exposure`, `shadowsHighlights`), tone (`levels`, `curves`), colour (`hueSaturation`, `vibrance`, `temperature`, `colorBalance`, `photoFilter`, `gradientMap`, `grayscale`, `sepia`, `invert`), stylize (`threshold`, `posterize`, `pixelate`), blur (`blur`, `motionBlur`, `surfaceBlur`), detail (`sharpen`, `clarity`, `noise`), `vignette`, auto (`autoTone`, `autoContrast`, `autoColor`) and `look` (`"look": "film"` — 20 graded styles). Parameters, ranges and defaults: [catalog.md](catalog.md). Recipes: [retouching.md](retouching.md).

```json
[
  { "type": "levels", "black": 20, "white": 235, "gamma": 1.05 },
  { "type": "curves", "rgb": [[0, 0], [64, 54], [192, 204], [255, 255]] },
  { "type": "colorBalance", "shadows": [-10, 0, 10], "highlights": [10, 0, -10] },
  { "type": "look", "look": "cinema", "amount": 0.7 }
]
```

## Masks

A mask hides parts of a layer: white (or opaque) = visible, black (or transparent) = hidden. Exactly one of:

- **image** `{ "src": "assets/masks/photo-cutout.png" }` — luminance × alpha of a PNG; written by `remove-bg` / `mask generate` (AI, colour range) and the Studio;
- **shape** `{ "shape": "rect" | "ellipse", "x", "y", "width", "height", "radius"? }`;
- **gradient** `{ "gradient": { "type": "linear", "angle": 0, "stops": ["black", "white"] } }` — a fade.

Plus `invert`, `feather` (edge blur, px), `density` (0..1: how much it hides) and `enabled`. On layers with a box (image, text, shape) the mask is in **layer-local** pixels and moves with the layer (an image mask is stretched over the box); on fill, adjustment and group layers it is in canvas pixels.

A masked **copy** of the photo is the usual way to change one region: `mask generate photo --target copy` duplicates the layer, masks the copy and leaves the original whole; filters on the copy then touch only the selection (skin smoothing, background blur, a bluer sky).

## Layer effects

Drawn from the layer's alpha after its filters and mask.

| Effect | Parameters (defaults) |
|---|---|
| `dropShadow` | `color` (#000), `opacity` (0.5), `angle` (135 = down-right), `distance` (12), `blur` (16), `spread` (0) |
| `outerGlow` | `color` (#fff), `opacity` (0.6), `blur` (20), `spread` (0) |
| `innerShadow` | `color`, `opacity`, `angle`, `distance` (6), `blur` (10) |
| `stroke` | `color` (#fff), `width` (6), `position` (`outside` / `center` / `inside`), `opacity` |
| `colorOverlay` | `color` (required), `opacity`, `blend` |

## Validation

`agentphoto doc validate` (MCP `doc_validate`) returns issues `{ severity, code, path, message, hint }` with JSON paths agents feed back into patches (`layers#title.size`, `layers#photo.filters[0].radius`). Errors block writes; warnings (unknown fields or parameters, ignored) come with "did you mean" hints; infos flag things like a font that is not bundled. `check` adds what needs the files: missing assets, unknown library images, layers off the canvas, upscaled photos, text that may overflow, heavy documents, licences.

## Versioning

`version` is 1. Changes to the format are additive; a breaking change would bump `DOC_VERSION` (also in `dist/version.json` as `docVersion`) and come with a migration in `normalizeDoc`.
