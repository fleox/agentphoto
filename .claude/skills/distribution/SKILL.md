# Distribution — contributor notes (this repo)

Read [CLAUDE.md](../../../CLAUDE.md) and [AGENTS.md](../../../AGENTS.md) first. Don't commit or push unless asked. Everything public is in English. Mirror of Agent3D (`../agent-3d/`): when in doubt, do what it does.

## Skills

- Four skills: `agentphoto-retouch` (core), `agentphoto-cutout`, `agentphoto-design`, `agentphoto-publish`. Frontmatter: `name` (= folder), `description` (what + when to use, < 1024 chars), `license: PolyForm-Noncommercial-1.0.0`, `compatibility`, `metadata.version` (= package.json), `allowed-tools`.
- Every command: `npx -y @fleox/agentphoto@<version> <command> … --json` on **one line**, run for real in order on a scratch project (outside the repo) before it is written. Use `my-photo` as the project name so a skill's commands replay as a sequence.
- Full documents in ```json blocks (`"version"` + `"layers"`) must validate without warnings; render them and look before adding them.
- `npm run build && node scripts/check-skills.mjs` must pass.

## README and docs

- `README.md` is also the npm page: absolute links (`https://github.com/fleox/agentphoto/blob/main/…`, images from `https://raw.githubusercontent.com/fleox/agentphoto/main/…`); only anchors stay relative.
- Numbers (28 filters, 20 looks, 15 fonts, 13 size presets, 8 templates) come from `agentphoto catalog --json` and `templates list --json`: re-count when they change.
- `docs/cli.md` reference: `node scripts/build-cli-docs.mjs` (`--check` in CI; `scripts/cli-docs.test.ts` in `npm test`). `docs/catalog.md` is generated by the tests; `docs/studio-api.md` belongs to the CLI.
- `docs/images/*.jpg`: real renders, < 150 KB, regenerated from the recipes in `plugin/skills/agentphoto-retouch/references/recipes.md` and `docs/retouching.md`.
- Never describe planned features as existing; check the Studio source before describing a tool.

## Release

`npm version patch|minor|major` runs `scripts/sync-version.mjs` (plugin.json, skills' `metadata.version`, every pinned `@fleox/agentphoto@x.y.z` in skills, README, AGENTS.md and docs), the build and the CLI docs. Add the `changelog.json` entry (newest first) before publishing; `prepublishOnly` runs typecheck, tests, build and check-skills.
